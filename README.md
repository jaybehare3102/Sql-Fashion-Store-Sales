-- This project focuses on analyzing a fashion retail database using SQL to derive meaningful business insights. 
The dataset simulates real-world e-commerce operations including customers, products, sales transactions, and inventory management.

--Objectives
Analyze sales performance across countries and channels
Identify top-selling products and categories
Perform customer segmentation based on spending behavior
Track monthly sales trends and growth
Evaluate inventory levels and stock performance

-- Database Structure

The database consists of the following tables:

Customers
Products
Sales
Sales Items
Campaigns
Channels
Stock

These tables are connected using primary and foreign keys to maintain relational integrity.

-- Tools & Technologies
MySQL (MySQL Workbench)
SQL
-- Key Analysis Performed
Revenue analysis by country and channel
Top-performing products and categories
Customer lifetime value (CLV)
Monthly sales trend and growth analysis
Inventory and stock insights
Product bundling (frequently bought together)

-- Skills Demonstrated
Complex JOIN operations
Aggregations and GROUP BY
Subqueries and CTEs
Window functions (RANK, DENSE_RANK, ROW_NUMBER, LAG)
Data modeling and relational schema design

--Outcome

The project demonstrates the ability to transform raw transactional data into actionable insights, supporting data-driven decision-making in a retail business environment.
